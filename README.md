# 智能搬运小车电控(第一版)

2027 年第十届中国大学生工程实践与创新能力大赛「智能搬运赛项」搬运机器人电控代码。
基于 **RoboMaster A 板(STM32F427IIH6, 168MHz)+ FreeRTOS V11.1.0 + 标准外设库**,四轮麦轮底盘,四路张大头 Emm_V5 闭环步进电机(CAN2)。

## 功能特性

- **运动控制**:麦轮运动学(前进/平移/45° 斜走/原地旋转),四轮同步启动
- **定位系统**:RS485 双绝对值编码器(X/Y 双测量轮直读坐标, 17bit, 掉电归零), Modbus 轮询
- **双陀螺仪方案**(共用 USART6/PG9, 开关互斥切换, 改后重新上电):
  - 轮趣 WHEELTEC FDI 惯导(FDILink 协议 921600, 例程逐行移植, 当前启用)
  - BNO085(UART RVC 模式 115200)
- **定位闭环**(yaw 航向保持 + 位置 PID, 全段陀螺仪校准):
  - 45° 斜走段(右前/左前/右后/左后, 按出发区镜像)
  - 直线行驶段(纯 PID)
  - 缓行扫码段(6RPM 低速 + MaixCam 扫到二维码即触发)
  - 二维码校准段(横向平移对位到画面 300~340, 停车并回传位置)
  - 回右上角点位段(目标按出发区自动换算)
- **二维码识别**:MaixCam 经 UART8 回传任务码 + 码中心坐标, 转发任务码显示屏
- **无线链路**:UART7(ZigBee) 接收上位机路线/动作指令, 整帧回传确认

## 串口协议(UART7, 115200-8-N-1)

帧格式:`AA 55 | CMD | 载荷 | SUM | 0D 0A`

| CMD | 功能 |
|---|---|
| 0x01 / 0x03 | 路线段下发(直角段 / 含45°段) |
| 0x04 | 动作指令(1前进 2后退 3顺时针转90° 4逆时针转90°) |
| 0x05 | 定位闭环(SUB: 0直线 1右前45° 2左转 3右转 4左前45° 5缓行扫码 6二维码校准 7回右上角) |
| 0x06 | 中止一切闭环 |
| 0x07 | 一键任务链(45° + 直线 + 缓行扫码) |
| 0x10 / 0x11 | 脉冲定距运动(调试)及应答 |

完整协议与现成指令见 [`../文档/串口协议.md`](../文档/串口协议.md),配套帧生成工具 [`../文档/帧生成器.html`](../文档/帧生成器.html)。

## 工程结构

```
├── User/            main.c(初始化+任务创建)、中断向量
├── Task/            motor_task(运动/闭环/阶段状态机)、odom_task(里程计)、
│                    lcd_task(三页显示+协议维护)、pid、servo_task、key_task
├── Hardware/        Emm_V5(CAN电机)、Encoder_RS485、bno08x_uart_rvc、lunqu_imu、
│                    route_rx(上位机协议)、uart7/uart8、LCD、Servo、Buzzer、can
├── Library/         STM32F4 标准外设库
├── FreeRTOS/        FreeRTOS V11 内核
├── Start/ System/   启动文件与系统初始化
└── Project.uvprojx  Keil MDK5 工程
```

## 构建与烧录

1. Keil MDK5(ARMCC V5.06)打开 `Project.uvprojx`
2. F7 编译(0 错 0 警),F8 烧录
3. 陀螺仪开关在 `User/main.c` 顶部(`Bno085_RunFlag` / `lunqu_RunFlag`),改后重新上电

## 关键可调参数

| 位置 | 参数 |
|---|---|
| `Task/motor_task.c` 宏区 | 到位容差、二维码缓行区宽度/速度、45° 转速、转向 PID、YAW/TURN 输出方向符号 |
| `Task/odom_task.c` | 压地轮周长(标定)、X/Y 安装方向符号、定位反馈轴 |
| `Hardware/lunqu_imu.c` | 轮趣串口波特率 |

## 任务阶段状态机

```
0 IDLE ──05帧/07帧──> 1 DIAG 45°斜走 ──段末──> 2 LINE 直线行驶
                                                    │ 距目标<15cm
                                                    ▼
              3 DONE 停车 <──扫到码── 5 SLOW 缓行+扫码 <──┘
                    │
                    └──> 6 QRCAL 二维码校准(对位300~340+回传pos) ──> 3 DONE
任意阶段 06 帧回 IDLE;4 TURN 原地转向独立触发
```

> 硬件接线、引脚占用与标定方法见代码内注释与 `移植说明.md`。
