## PI6灯光PWM（2026-11-16）

- **行驶掉线诊断与恢复**：LCD新增STOP ODOM / NO PROGRESS / TIMEOUT。编码器连续3次读失败后仅重建STM32 USART2，恢复操作每秒最多一次，不清零编码器或里程；连续5次失败仍停车，当前行驶段保留并等待连续3次成功后自动续跑。ODOM诊断页REC记录恢复次数。Delay_ms在任务中使用vTaskDelay，上电/微秒延时使用DWT，不再写SysTick。实际通信断流根因待实车验证。

- **里程计中断收发v2**：请求通过TXE中断连续发送，TC中断在最后停止位完成后立即切换RS485到接收；避免任务被夹取控制抢占时延迟释放总线。接收缓存保留，等待均使用RTOS，有界超时。ODOM故障页增加HW/D/IRQ/TX，正常接收配置HW=7F、D=0。该时序缺陷已在软件中复现并修正，实车待验证。

- **里程计串口接收**：USART2中断缓存回包，减少RTOS任务切换造成的漏字节；帧头重同步、CRC校验、40ms有界等待和串口错误清除。ODOM故障页新增IRQ RX v1、请求/有效帧/字节数及CRC/ORE等计数，供实车区分无应答与接收错误。

- **里程计全程读取与原料区回位**：视觉、抓取、圆环及码垛作业均不暂停RS485读取。真实路线在发送转盘识别模式4前，仅保存一次原始里程计位置；第三块装车收尾后，等新的在线读数（最多1秒），沿原里程计轴按90°航向回到保存位置，确认回位后才继续下一上传路段。保存目标不被视觉或抓取期间的新读数覆盖；独立1E仍抓取收尾后停车。


- **RM终点稳定控制**：位置P与速度PI串联，取消长行程位置积分和死区旧输出保持；按剩余距离提前减速，加速/减速斜率分别24000/48000转子rpm/s，位置环速度系数40、转子上限16000RPM。进入±0.2°且低速后目标速度归零，偏移超过±0.5°重新纠正，速度PI保留负载保持力。中途换目标沿用速度和内环积分，同目标不重置；到位判断恢复低速条件，完整到位另需连续100ms稳定。参数集中在`Hardware/arm_m2006.c`，真实路线及网页0x16共用，角度目标与机械行程不变。软件测试已通过，实际效果需带机构验证。

- **原料区调试网页**：[原料区调试.html](docs/原料区调试.html)，选批次后一键完成机构准备、视觉定位和三块装车，当前朝向记为90°，收尾后停车。原料区丝杆最多等1秒、同步带最多等2秒，只等9F主动到位帧，不进行位置回读，未确认也放行；RM反馈有效时最多等1.5秒，提前到位立即继续，未到位超时也放行；反馈失效仍报错；不改变粗加工和暂存参数。

- **上电任务码**：默认注入 `156+123+516+231`，复用任务码解析与环号查询接口；后续扫码或网页1B注入的新任务码可覆盖。
- **运动控制**:麦轮运动学(前进/平移/45° 斜走/原地旋转),四轮同步启动
- **定位系统**:RS485 单里程计(站号1, 17bit, 掉电归零), Modbus 仅轮询站号1
- **夹爪伸出**:M2006 P36 + C610(ID1)，CAN1(PD0/PD1，1Mbps)；上电当前位置记0°，原料区转盘视觉定位停车后伸出至120°。14独立调试同样执行伸出，到位后保持，不自动缩回。
- **RM电机角度调试**:串口帧生成器可设定−360°～+360°的绝对目标；独立调试帧0x16，先在安全行程内使用。
- **站点视觉修正陀螺仪基准**：真实路线两轮粗加工、两轮暂存在视觉XY及视觉Yaw全部合格后、首块取料前，仅校正一次所选陀螺仪软件Yaw基准：粗加工将当前朝向记为270°，暂存记为0°。例如对位后原读数260°，粗加工重标为270°；后续新帧继续沿用该偏移。此操作不额外转动车体、不暂停或清零编码器；同时同步路线航向并重置直行航向控制历史，避免离站瞬间误纠偏。只在自动对位成功且任务码校验通过后执行，视觉未完成/超时/中止不执行；独立视觉调试、1C纯机械调试和原料区保持原行为。航向反馈由main.c所选的HWT101或轮趣提供。
- **圆环通信**:两批粗加工区及第一批暂存区作业对准后进入圆环识别，保持编码器持续读取，按固定ID找齐三环，依次校准平均XY→Yaw→平均XY（目标320±3、240±3像素，Yaw±0.5°，每阶段连续5个新结果）；完成后按扫码顺序自动放三块，粗加工放完后按扫码顺序取回原槽位并继续已上传路线；暂存放完收起后停车。上电默认Yaw校正方向为-1（正视觉Yaw用负旋转），无需先发串口；15帧仍可覆盖方向，06退出识别并返回相机画面，里程计持续读取。第二批暂存区到站发送RDK模式5（AA 55 10 01 05 16 0D 0A），使用单中心点及视觉Yaw对位，完成后按第二批物料顺序叠到同色第一批所在环，丝杆目标32750；第三块收起后停车。独立1D只对位，完成后需另发1C/04放料。
- **站点放料**:同步带中心7050（上电0、抓取1540、范围0~10000）；同步带电机端转速2200RPM、加速度档210，路线及独立0x19调试共用；两轮粗加工按本批任务码、第一轮暂存按第一批任务码依次取A/B/C槽。第一块取料前下发槽位角度；第二、第三块沿用提前转好的槽位，回到1540后不重复下发270°舵机角度。第一块取料三轴1540/107°/21500并行；第二、第三块在返回阶段已全部到位后直接夹紧，不重复下发取料定位，夹爪按main.c配置角度夹紧400ms后，单独将丝杆抬到15000并等到位；丝杆15000确认后，同步带与RM同时到当前物料目标环并全部确认；随后丝杆单独下放时，同一拍将270°舵机转到下一待取物料保存的原槽位(当前第一块下放时转B槽150°、第二块下放时转C槽270°)，不等待、不驻留；第三块无下一待放物料，保持当前槽位。放料目标按环号1=5410/431°/56750、2=7128/319°/56750、3=8782/446°/56750（同步带/RM/丝杆，第二轮暂存丝杆均32750），先同步带与RM同时到位，再单独下放丝杆并确认到位，随后稳定等待800ms，夹爪直接到main.c配置的完全松开角度(当前48°)并等待400ms，取消前20°缓张开。前两块放料48°松开400ms后，先丝杆单独回21500到位，再同时同步带回1540和RM回107°，全部到位后直接109.5°夹紧下一块并等400ms，删除重复取料定位，不重复下发三轴或270°舵机；粗加工第三块松开后直接回25000并接取回，暂存第三块仍回12500/1540后停车，06退出。270°舵机只发0/120/270°，不等待。
- **站点运动等待**：两轮粗加工、两轮暂存及独立1C调试共用：丝杆目标0～10000脉冲（含10000）最多等1秒，超过10000最多等2秒、同步带最多等2.5秒、RM放料对环最多等2秒、取料/取回/收回最多等1秒；提前到位则提前放行，否则各轴超时后直接结束等待。并行组需等所有参与轴分别确认或达到各自超时；不进行位置回读。RM到位仍按±1°且低速判断；通信失联、目标下发失败及06中止仍停车。超时放行不代表机械实际到位，也不主动停止该轴；计时使用RTOS tick，不调用裸机Delay。
- **粗加工取回**:两轮粗加工均在第三块松开并等待400ms后，先丝杆回25000确认；随后按保存的扫码顺序、环号和原槽位逐块取回。270°舵机转该物料原槽位(0/120/270°，不等待)，同步带和RM同时到对应圆环并结束等待，再单独下放丝杆56750并结束等待，夹紧109.5°等400ms→丝杆12500到位→同步带1540与RM107°同时到位→丝杆19500到位→松开48°等400ms→丝杆12500到位，再取下一块。夹爪角度共用main.c配置。三块取回收起后，路线模式退出识别、等待新的有效编码器数据(最多1s)，再执行下一上传路段；独立1C停车。槽位与环号独立保存，不按环号排序或推算槽位。
- **网页独立放料**:两份帧生成器均可连接UART7，先用1B注入任务码，再用“站点取放三个物块(1C)”选择第一轮粗加工/第二轮粗加工/第一轮暂存/第二轮暂存；跳过视觉直接复用上述流程；1C/01、1C/02放完再取回三块后停车，1C/03、1C/04只放料收起后停车，支持顶部06立即中止。
- **航向传感器**：保留HWT101和轮趣FDILink，通过 `User/main.c` 的 `IMU_Select` 单变量选择：`0/IMU_SOURCE_HWT101`（当前选择，115200，使用上位机已设100Hz，首个有效角度帧就绪），`1/IMU_SOURCE_LUNQU`（原921600，等首个AHRS帧就绪，不发送HWT配置）。修改后重新编译烧录并上电；共用USART6/PG9，仅接所选一款，HWT101模块RX无需连接。LCD分别显示HWT:READY或LQ :READY。转向±2°内连续3个新航向帧确认，保留原总超时，不增加100ms断流停车。详见 [`docs/陀螺仪选择.md`](docs/陀螺仪选择.md)。
- **定位闭环**(yaw 航向保持 + 位置 PID, 全段陀螺仪校准):
  - 45° 斜走段(右前/左前/右后/左后, 按出发区镜像)
  - 直线行驶段(纯 PID)
  - 缓行扫码段(6RPM 低速 + MaixCam 扫到二维码即触发)
  - 二维码校准段(横向平移对位到画面 300~340, 停车并回传位置)
  - 回右上角点位段(目标按出发区自动换算)
- **二维码识别**:MaixCam 经 UART8 回传任务码 + 码中心坐标, 转发任务码显示屏
- **无线链路**:UART7(ZigBee) 接收上位机路线/动作指令, 整帧回传确认

## 串口协议(UART7, 115200-8-N-1)

帧格式:`AA 55 | CMD | 载荷 | SUM | 0D 0A`

| CMD | 功能 |
|---|---|
| 0x01 / 0x03 | 路线段下发(直角段 / 含45°段) |
| 0x04 | 动作指令(1前进 2后退 3顺时针转90° 4逆时针转90°) |
| 0x05 | 定位闭环(SUB: 0直线 1右前45° 2左转 3右转 4左前45° 5缓行扫码 6二维码校准 7回右上角) |
| 0x06 | 中止一切闭环 |
| 0x07 | 一键任务链(45° + 直线 + 缓行扫码) |
| 0x10 / 0x11 | 脉冲定距运动(调试)及应答 |

完整协议与现成指令见 [`docs/串口协议.md`](docs/串口协议.md),配套帧生成工具 [`docs/帧生成器.html`](docs/帧生成器.html)。

## 构建与烧录

## 任务阶段状态机

```
0 IDLE ──05帧/07帧──> 1 DIAG 45°斜走 ──段末──> 2 LINE 直线行驶
                                                    │ 距目标<15cm
                                                    ▼
              3 DONE 停车 <──扫到码── 5 SLOW 缓行+扫码 <──┘
                    │
                    └──> 6 QRCAL 二维码校准(对位300~340+回传pos) ──> 3 DONE
任意阶段 06 帧回 IDLE;4 TURN 原地转向独立触发
```

> 硬件接线、引脚占用与标定方法见代码内注释与 `移植说明.md`。

- **原料区参数**：路线先执行原料区到站节点，对准作业航向90°后才启动机构准备（转向需进入±2°并连续确认3个新角度帧；已经对准时直接准备）。同步带7040、RM455°，同步带确认后夹爪70°（只下发，不等待）；视觉对位后RM285°和丝杆21000并行。每块109°夹紧400ms→丝杆12500→同步带1540/RM107°并行→丝杆19500→70°松开400ms→前两块同步带7040/RM285°/丝杆21000及270°舵机分度并行；第三块直接同时下发同步带7040、RM107°、丝杆12500、夹爪70°和270°舵机转粗加工第一个待放物料原槽(当前A槽30°，复用槽位映射，不由环号推算)，不先回285°/21000。收尾丝杆1秒/同步带2秒未确认也放行，RM最多等3秒，反馈正常时未到位也放行；两只舵机均不额外驻留、不等反馈。路线和1A共用抓取序列；真实路线三块均先打开接收再发一次当前颜色，不重复发送；等待RDK状态帧AA 55 11 02 STATE COLOR CK 0D 0A（9字节），收到首个STATE=5且颜色匹配的完整有效帧即夹取并关闭接收，0x18确认帧（8字节）仅供诊断，不是夹取前提，每块从颜色发送起最长等30秒。普通行驶到原料点或途经该点不会自动取料。

两轮粗加工区及两轮暂存区到站预定位统一为：RM190°、同步带7040、180°舵机48°，下发后立即启动本站视觉模式，机构动作与对位并行，不等待机构到位；第一轮暂存及粗加工发模式1，第二轮暂存发模式5。放料目标及原料区参数不变。
