# 智能搬运小车电控(第一版)

2027 年第十届中国大学生工程实践与创新能力大赛「智能搬运赛项」搬运机器人电控代码。
基于 **RoboMaster A 板(STM32F427IIH6, 168MHz)+ FreeRTOS V11.1.0 + 标准外设库**,四轮麦轮底盘,四路张大头 Emm_V5 闭环步进电机(CAN2)。

## 功能特性

- **运动控制**:麦轮运动学(前进/平移/45° 斜走/原地旋转),四轮同步启动
- **定位系统**:RS485 单里程计(站号1, 17bit, 掉电归零), Modbus 仅轮询站号1
- **夹爪伸出**:M2006 P36 + C610(ID1)，CAN1(PD0/PD1，1Mbps)；上电当前位置记0°，原料区转盘视觉定位停车后伸出至120°。14独立调试同样执行伸出，到位后保持，不自动缩回。
- **RM电机角度调试**:串口帧生成器可设定−360°～+360°的绝对目标；独立调试帧0x16，先在安全行程内使用。
- **圆环通信**:两批粗加工区及第一批暂存区作业对准后进入圆环识别，暂停编码器读取，按固定ID找齐三环，依次校准平均XY→Yaw→平均XY（目标320±3、240±3像素，Yaw±0.5°，每阶段连续5个新结果）；完成后按扫码顺序自动放三块，粗加工放完后按扫码顺序取回原槽位并继续已上传路线；暂存放完收起后停车。上电默认Yaw校正方向为-1（正视觉Yaw用负旋转），无需先发串口；15帧仍可覆盖方向，06退出恢复读取和相机。第二批暂存区到站发送RDK模式5（AA 55 10 01 05 16 0D 0A），使用单中心点及视觉Yaw对位，完成后按第二批物料顺序叠到同色第一批所在环，丝杆目标131000；第三块收起后停车。独立1D只对位，完成后需另发1C/04放料。
- **站点放料**:同步带中心7050（上电0、抓取1400、范围0~10000）；同步带电机端转速1200RPM、加速度档200，路线及独立0x19调试共用；两轮粗加工按本批任务码、第一轮暂存按第一批任务码依次取A/B/C槽。第一块取料前下发槽位角度；第二、第三块沿用提前转好的槽位，回到1400后不重复下发270°舵机角度。第一块取料三轴1400/107°/86000并行；第二、第三块在返回阶段已全部到位后直接夹紧，不重复下发取料定位，夹爪按main.c配置角度夹紧400ms后，单独将丝杆抬到60000并等到位；丝杆60000确认后，先同步带到当前物料目标环并确认；启动RM和丝杆下放时，同一拍将270°舵机转到下一待取物料保存的原槽位(当前第一块下放时转B槽120°、第二块下放时转C槽240°)，不等待、不驻留；第三块无下一待放物料，保持当前槽位。放料目标按环号1=5410/431°/227000、2=7128/319°/227000、3=8782/446°/227000（同步带/RM/丝杆，第二轮暂存丝杆均131000），先同步带到位，再同时执行RM和丝杆，两者到位后稳定等待800ms，夹爪直接到main.c配置的完全松开角度(当前48°)并等待400ms，取消前20°缓张开。前两块放料48°松开400ms后，先丝杆单独回86000到位，再同时同步带回1400和RM回107°，全部到位后直接109.5°夹紧下一块并等400ms，删除重复取料定位，不重复下发三轴或270°舵机；粗加工第三块松开后直接回100000并接取回，暂存第三块仍回50000/1400后停车，06退出。270°舵机只发0/120/240°，不等待。
- **粗加工取回**:两轮粗加工均在第三块松开并等待400ms后，先丝杆回100000确认；随后按保存的扫码顺序、环号和原槽位逐块取回。270°舵机转该物料原槽位(0/120/240°，不等待)，三轴同时到对应圆环(丝杆227000)，夹紧109.5°等400ms→丝杆50000到位→同步带1400与RM107°同时到位→丝杆78000到位→松开48°等400ms→丝杆50000到位，再取下一块。夹爪角度共用main.c配置。三块取回收起后，路线模式退出识别、恢复编码器并等新有效数据(最多1s)，再执行下一上传路段；独立1C停车。槽位与环号独立保存，不按环号排序或推算槽位。
- **网页独立放料**:两份帧生成器均可连接UART7，先用1B注入任务码，再用“站点取放三个物块(1C)”选择第一轮粗加工/第二轮粗加工/第一轮暂存/第二轮暂存；跳过视觉直接复用上述流程；1C/01、1C/02放完再取回三块后停车，1C/03、1C/04只放料收起后停车，支持顶部06立即中止。
- **双陀螺仪方案**(共用 USART6/PG9, 开关互斥切换, 改后重新上电):
  - 轮趣 WHEELTEC FDI 惯导(FDILink 协议 921600, 例程逐行移植, 当前启用)
  - BNO085(UART RVC 模式 115200)
- **定位闭环**(yaw 航向保持 + 位置 PID, 全段陀螺仪校准):
  - 45° 斜走段(右前/左前/右后/左后, 按出发区镜像)
  - 直线行驶段(纯 PID)
  - 缓行扫码段(6RPM 低速 + MaixCam 扫到二维码即触发)
  - 二维码校准段(横向平移对位到画面 300~340, 停车并回传位置)
  - 回右上角点位段(目标按出发区自动换算)
- **二维码识别**:MaixCam 经 UART8 回传任务码 + 码中心坐标, 转发任务码显示屏
- **无线链路**:UART7(ZigBee) 接收上位机路线/动作指令, 整帧回传确认

## 串口协议(UART7, 115200-8-N-1)

帧格式:`AA 55 | CMD | 载荷 | SUM | 0D 0A`

| CMD | 功能 |
|---|---|
| 0x01 / 0x03 | 路线段下发(直角段 / 含45°段) |
| 0x04 | 动作指令(1前进 2后退 3顺时针转90° 4逆时针转90°) |
| 0x05 | 定位闭环(SUB: 0直线 1右前45° 2左转 3右转 4左前45° 5缓行扫码 6二维码校准 7回右上角) |
| 0x06 | 中止一切闭环 |
| 0x07 | 一键任务链(45° + 直线 + 缓行扫码) |
| 0x10 / 0x11 | 脉冲定距运动(调试)及应答 |

完整协议与现成指令见 [`docs/串口协议.md`](docs/串口协议.md),配套帧生成工具 [`docs/帧生成器.html`](docs/帧生成器.html)。

## 工程结构

```
├── User/            main.c(初始化+任务创建)、中断向量
├── Task/            motor_task(运动/闭环/阶段状态机)、odom_task(里程计)、
│                    lcd_task(三页显示+协议维护)、pid、servo_task、key_task
├── Hardware/        Emm_V5(CAN电机)、Encoder_RS485、bno08x_uart_rvc、lunqu_imu、
│                    route_rx(上位机协议)、uart7/uart8、LCD、Servo、Buzzer、can
├── Library/         STM32F4 标准外设库
├── FreeRTOS/        FreeRTOS V11 内核
├── Start/ System/   启动文件与系统初始化
└── Project.uvprojx  Keil MDK5 工程
```

## 构建与烧录

1. Keil MDK5(ARMCC V5.06)打开 `Project.uvprojx`
2. F7 编译(0 错 0 警),F8 烧录
3. 陀螺仪开关在 `User/main.c` 顶部(`Bno085_RunFlag` / `lunqu_RunFlag`),改后重新上电

## 关键可调参数

| 位置 | 参数 |
|---|---|
| `Task/motor_task.c` 宏区 | 到位容差、二维码缓行区宽度/速度、45° 转速、转向 PID、YAW/TURN 输出方向符号 |
| `Task/odom_task.c` | 里程计1压地轮周长(标定)、单站轮询 |
| `Hardware/lunqu_imu.c` | 轮趣串口波特率 |

## 任务阶段状态机

```
0 IDLE ──05帧/07帧──> 1 DIAG 45°斜走 ──段末──> 2 LINE 直线行驶
                                                    │ 距目标<15cm
                                                    ▼
              3 DONE 停车 <──扫到码── 5 SLOW 缓行+扫码 <──┘
                    │
                    └──> 6 QRCAL 二维码校准(对位300~340+回传pos) ──> 3 DONE
任意阶段 06 帧回 IDLE;4 TURN 原地转向独立触发
```

> 硬件接线、引脚占用与标定方法见代码内注释与 `移植说明.md`。

- **原料区参数**：路线先执行原料区到站节点，对准作业航向90°后才启动机构准备（转向需进入±2°并连续确认8拍；已经对准时直接准备）。同步带7040、RM455°，同步带确认后夹爪70°（只下发，不等待）；视觉对位后RM285°和丝杆84000并行。每块109°夹紧400ms→丝杆20000→同步带1400/RM107°并行→丝杆78000→70°松开400ms→前两块同步带7040/RM285°/丝杆84000及270°舵机分度并行；第三块直接同时下发同步带7040、RM107°、丝杆50000、夹爪70°和270°舵机转粗加工第一个待放物料原槽(当前A槽0°，复用槽位映射，不由环号推算)，不先回285°/84000。收尾只等待三轴到位，两只舵机均不额外驻留、不等反馈。路线和1A共用抓取序列；真实路线三块均先发当前颜色，再等RDK触发帧AA 55 11 00 11 0D 0A，收到首个完整有效帧即夹取并关闭接收，每块等待最长30秒。普通行驶到原料点或途经该点不会自动取料。

两轮粗加工区及两轮暂存区到站预定位统一为：RM190°、同步带7040、180°舵机48°，下发后立即启动本站视觉模式，机构动作与对位并行，不等待机构到位；第一轮暂存及粗加工发模式1，第二轮暂存发模式5。放料目标及原料区参数不变。
