# 智能搬运小车电控(第一版)

2027 年第十届中国大学生工程实践与创新能力大赛「智能搬运赛项」搬运机器人电控代码。
基于 **RoboMaster A 板(STM32F427IIH6, 168MHz)+ FreeRTOS V11.1.0 + 标准外设库**,四轮麦轮底盘,四路张大头 Emm_V5 闭环步进电机(CAN2)。

## 功能特性

- **运动控制**:麦轮运动学(前进/平移/45° 斜走/原地旋转),四轮同步启动
- **定位系统**:RS485 单里程计(站号1, 17bit, 掉电归零), Modbus 仅轮询站号1
- **夹爪伸出**:M2006 P36 + C610(ID1)，CAN1(PD0/PD1，1Mbps)；上电当前位置记0°，原料区转盘视觉定位停车后伸出至120°。14独立调试同样执行伸出，到位后保持，不自动缩回。
- **RM电机角度调试**:串口帧生成器可设定−360°～+360°的绝对目标；独立调试帧0x16，先在安全行程内使用。
- **圆环通信**:两批粗加工区及第一批暂存区作业对准后进入圆环识别，暂停编码器读取，按固定ID找齐三环，依次校准平均XY→Yaw→平均XY（目标320±3、240±3像素，Yaw±0.5°，每阶段连续5个新结果）；完成后按扫码顺序自动放三块，收起后停车（不取回、不续路）。上电默认Yaw校正方向为-1（正视觉Yaw用负旋转），无需先发串口；15帧仍可覆盖方向，06退出恢复读取和相机。第二批暂存区到站发送RDK模式5（AA 55 10 01 05 16 0D 0A），使用单中心点及视觉Yaw对位，完成后按第二批物料顺序叠到同色第一批所在环，丝杆目标150000；第三块收起后停车。独立1D只对位，完成后需另发1C/04放料。
- **站点放料**:同步带中心7050（上电0、抓取1400、范围0~10000）；两轮粗加工按本批任务码、第一轮暂存按第一批任务码依次取A/B/C槽。取料三轴1400/107°/86000并行，夹爪按main.c配置角度夹紧400ms后，单独将丝杆抬到40000并等到位；放料目标按环号1=5410/431°/222000、2=7128/319°/222000、3=8782/446°/222000（同步带/RM/丝杆，第二轮暂存丝杆均150000），先同步带到位，再同时执行RM和丝杆，两者到位后稳定等待800ms，夹爪用400ms从main.c配置的夹紧角度向松开方向平滑张开20°，再直接到main.c配置的完全松开角度并等待400ms。每块先丝杆回50000，再同步带到1400；第三块完成后保持停车，06退出。270°舵机只发0/120/240°，不等待。
- **网页独立放料**:两份帧生成器均可连接UART7，先用1B注入任务码，再用“放置三个物块(1C)”选择第一轮粗加工/第二轮粗加工/第一轮暂存/第二轮暂存；跳过视觉直接复用上述取放流程，收起后停车，支持顶部06立即中止。
- **双陀螺仪方案**(共用 USART6/PG9, 开关互斥切换, 改后重新上电):
  - 轮趣 WHEELTEC FDI 惯导(FDILink 协议 921600, 例程逐行移植, 当前启用)
  - BNO085(UART RVC 模式 115200)
- **定位闭环**(yaw 航向保持 + 位置 PID, 全段陀螺仪校准):
  - 45° 斜走段(右前/左前/右后/左后, 按出发区镜像)
  - 直线行驶段(纯 PID)
  - 缓行扫码段(6RPM 低速 + MaixCam 扫到二维码即触发)
  - 二维码校准段(横向平移对位到画面 300~340, 停车并回传位置)
  - 回右上角点位段(目标按出发区自动换算)
- **二维码识别**:MaixCam 经 UART8 回传任务码 + 码中心坐标, 转发任务码显示屏
- **无线链路**:UART7(ZigBee) 接收上位机路线/动作指令, 整帧回传确认

## 串口协议(UART7, 115200-8-N-1)

帧格式:`AA 55 | CMD | 载荷 | SUM | 0D 0A`

| CMD | 功能 |
|---|---|
| 0x01 / 0x03 | 路线段下发(直角段 / 含45°段) |
| 0x04 | 动作指令(1前进 2后退 3顺时针转90° 4逆时针转90°) |
| 0x05 | 定位闭环(SUB: 0直线 1右前45° 2左转 3右转 4左前45° 5缓行扫码 6二维码校准 7回右上角) |
| 0x06 | 中止一切闭环 |
| 0x07 | 一键任务链(45° + 直线 + 缓行扫码) |
| 0x10 / 0x11 | 脉冲定距运动(调试)及应答 |

完整协议与现成指令见 [`docs/串口协议.md`](docs/串口协议.md),配套帧生成工具 [`docs/帧生成器.html`](docs/帧生成器.html)。

## 工程结构

```
├── User/            main.c(初始化+任务创建)、中断向量
├── Task/            motor_task(运动/闭环/阶段状态机)、odom_task(里程计)、
│                    lcd_task(三页显示+协议维护)、pid、servo_task、key_task
├── Hardware/        Emm_V5(CAN电机)、Encoder_RS485、bno08x_uart_rvc、lunqu_imu、
│                    route_rx(上位机协议)、uart7/uart8、LCD、Servo、Buzzer、can
├── Library/         STM32F4 标准外设库
├── FreeRTOS/        FreeRTOS V11 内核
├── Start/ System/   启动文件与系统初始化
└── Project.uvprojx  Keil MDK5 工程
```

## 构建与烧录

1. Keil MDK5(ARMCC V5.06)打开 `Project.uvprojx`
2. F7 编译(0 错 0 警),F8 烧录
3. 陀螺仪开关在 `User/main.c` 顶部(`Bno085_RunFlag` / `lunqu_RunFlag`),改后重新上电

## 关键可调参数

| 位置 | 参数 |
|---|---|
| `Task/motor_task.c` 宏区 | 到位容差、二维码缓行区宽度/速度、45° 转速、转向 PID、YAW/TURN 输出方向符号 |
| `Task/odom_task.c` | 里程计1压地轮周长(标定)、单站轮询 |
| `Hardware/lunqu_imu.c` | 轮趣串口波特率 |

## 任务阶段状态机

```
0 IDLE ──05帧/07帧──> 1 DIAG 45°斜走 ──段末──> 2 LINE 直线行驶
                                                    │ 距目标<15cm
                                                    ▼
              3 DONE 停车 <──扫到码── 5 SLOW 缓行+扫码 <──┘
                    │
                    └──> 6 QRCAL 二维码校准(对位300~340+回传pos) ──> 3 DONE
任意阶段 06 帧回 IDLE;4 TURN 原地转向独立触发
```

> 硬件接线、引脚占用与标定方法见代码内注释与 `移植说明.md`。

- **原料区参数**：到站同步带7040、RM455°，同步带确认后夹爪48°（只下发，不等待）；视觉对位后RM285°和丝杆84000并行。每块105°夹紧400ms→丝杆20000→同步带1400/RM107°并行→丝杆78000→48°松开400ms→同步带7040/RM285°/丝杆84000及270°舵机分度并行，等待三轴到位，不等待舵机反馈。路线和1A共用抓取序列。

两轮粗加工区及两轮暂存区到站预定位统一为：RM190°、同步带7040、180°舵机48°，下发后立即启动本站视觉模式，机构动作与对位并行，不等待机构到位；第一轮暂存及粗加工发模式1，第二轮暂存发模式5。放料目标及原料区参数不变。
