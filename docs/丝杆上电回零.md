# 丝杆上电碰撞回零（CAN 地址 6）

已接入 `User/main.c`，在所有 `xTaskCreate()` 和 `vTaskStartScheduler()` 之前完成。

## 接线与行为

- 丝杆张大头电机使用 Emm 固件，CAN 地址 **6**。
- 复用现有 CAN2：PB12=RX、PB13=TX，1 Mbps；通过 CAN 收发器接入现有总线。
- 上电等待驱动初始化，退出残留回零、解除堵转保护、使能、停止，配置碰撞回零参数。
- 主控发送模式 `2`（多圈无限位碰撞回零）、方向 `0`（CW 向上），不使用同步缓存。
- 驱动在转速低于检测阈值、相电流高于检测阈值且持续达到设定时间后判定碰撞。
- 主控确认回零结束且无失败标志后，读取实际转速连续三次不超过 2 RPM，采样间隔 20 ms，最长等待 1 秒。
- 读取电机状态；若堵转保护仍锁存，仅在确认回零完成后解除一次，必要时重新使能，并再次确认停稳、回零状态正常、电机保持使能且保护已解除。
- 发送 `0x0A` 将电机当前位置清零，再读回 `0x36` 确认位置接近零。成功路径无需额外发送急停 `FE`；失败退出仍保留急停。
- 成功后才创建任务、启动调度器。电机保持使能，不主动松开竖直丝杆。
- 回零参数只写 RAM，不反复写驱动 Flash；上电回零由主控触发。

这里清零的是电机位置坐标，使用 `Emm_V5_Reset_CurPos_To_Zero()`，不是仅设置单圈回零原点。

## 可调参数

集中在 `Hardware/lift_zdt.h`：

| 宏 | 当前值 | 含义 |
| --- | --- | --- |
| `LIFT_ZDT_ADDR` | 6 | 丝杆驱动地址；禁止广播或四轮地址 1～4 |
| `LIFT_HOME_SPEED_RPM` | 50 | CW 向上回零转速(放慢减小碰撞冲击) |
| `LIFT_HOME_TIMEOUT_MS` | 30000 | 驱动回零最长 30 秒；主控另加 1 秒通信余量 |
| `LIFT_STALL_SPEED_RPM` | 10 | 碰撞检测转速阈值 |
| `LIFT_STALL_CURRENT_MA` | 400 | 碰撞检测相电流阈值(调小=更早判停顶得更轻) |
| `LIFT_STALL_TIME_MS` | 100 | 满足碰撞条件的持续时间 |
| `LIFT_ZERO_TOLERANCE` | 16 | 读回零位允许的编码器抖动，约 0.088° |

回零转速当前为 100 RPM。例程普通运动接口标注支持 5000 RPM，但资料包中的 X42S 手册将回零速度范围列为 0～3000 RPM。

这些是调试值，尚未用实际丝杆验证。电流阈值应高于正常上升时的相电流，同时低于堵转时可达到的相电流。若正常运行尚未到顶就回零结束，需结合实测电流调整阈值；若顶住后不结束，也应检查电流阈值和驱动电流设置。提高转速后，应重新确认碰撞停止效果和零点重复性。若全行程需要超过 30 秒，应相应调整回零超时。

没有限位开关时，回零只能判断“遇到阻力”，无法区分顶部机械端点和中途卡阻，因此机械端点与全行程畅通情况需要实机确认。如果驱动另有碰撞后返回角度设置，应设为 0，以免零点偏离碰撞位置。

## 故障提示

屏幕显示 `Lift CW homing`，回零成功显示 `Lift zero OK` 后进入任务。失败显示 `Home failed:N`，绿色 LED 熄灭、红色 LED 闪烁，调度器不会启动。

失败页另显示十六进制 `CMD`（失败命令）、`RET`（返回值）、`ORG`（最后一次回零状态）、`MOT`（最后一次电机状态），以及十进制 `LEN`（CAN 数据长度）。这些值保留原始故障信息，不会被后续退出回零和急停命令覆盖。`MOT` 的 bit0 表示使能、bit3 表示堵转保护锁存；0 表示尚未读到或这两项均未置位，须结合失败命令判断。

例如 `CMD:9A RET:E2` 表示触发回零被拒绝；`CMD:FE RET:E2` 表示停止命令被拒绝；`CMD:0A RET:E2` 表示清零命令被拒绝。`E2` 通常表示参数或执行条件不满足，`EE` 表示格式错误。需要结合实际显示定位，不能只根据错误码 3 判断堵转检测是否成功。

程序已补充兼容触发回零的 `0x12`（已在零点）和 `0x9F`（回零完成）返回；仅对 `0x9A` 命令接受这些返回，并继续读取回零状态及验证清零结果。若驱动设置为仅完成时应答，触发回零的应答等待允许持续至回零超时加 1 秒。其他命令仍要求 `0x02`，不忽略真实的拒绝应答。

| N | 含义 |
| --- | --- |
| 1 | 地址不合法，与广播/四轮地址冲突 |
| 2 | 未收到匹配地址、功能码和校验字节的应答，或通信超时 |
| 3 | 驱动拒绝命令，或返回长度不符 |
| 4 | 编码器/校准未就绪、启动前已有过热/过流，或回零后电机未使能/堵转保护未解除 |
| 5 | 回零失败、编码器状态异常、过热或过流 |
| 6 | 主控等待回零超时 |
| 7 | 清零后读回位置超出容差，或符号字段异常 |
| 8 | 回零结束后转速未在 1 秒内稳定至不超过 2 RPM，或速度符号字段异常 |

### 到顶后 CMD:FE / RET:E2 的修正

实机照片显示 `Home failed:3 / CMD:FE / RET:E2 / LEN:3 / ORG:03`：回零状态无失败、无正在回零标志，但额外急停被拒绝，程序尚未执行位置清零。`ORG` 不包含电机堵转保护锁存状态，仅凭照片不能确认 `E2` 的具体驱动内部原因。

本版去掉成功回零后的多余 `FE` 命令，通过实际速度和电机状态确认停稳及保持使能，再清零和读回校验。若堵转保护锁存则按上述流程处理；真实回零失败、超时、未停稳和清零失败仍阻止调度器启动。回零速度为 100 RPM。

Keil Watch 可查看 `g_lift_home_result`；0 表示成功。故障退出时会尝试发送退出回零与急停；断线时无法保证电机收到命令，驱动自身的 30 秒回零超时作为后备。不自动失能竖直丝杆。
