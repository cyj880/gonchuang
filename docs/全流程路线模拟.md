## 四、障碍物绕行模板(抽签后按位置套用)

障碍物立在车道中央(φ50),车道宽 400,车宽 300 → 可通行净宽约 350,贴边绕行即可,**多数情况不需要大幅绕路**,只需在障碍物前留出变道空间:

```
前方障碍(距车头 d):
  1. 前进 (d - 250)mm        ← 停在障碍前 250mm
  2. 顺/逆时针转90°           ← 车头对准通道空侧
  3. 前进 ≈300mm             ← 横向让开(沿车道宽度方向)
  4. 顺/逆时针转90°           ← 车头回原行进方向
  5. 前进 (障碍直径+余量)mm    ← 越过障碍(≈300mm)
  6. 顺/逆时针转90°           ← 对准回原路线
  7. 前进 ≈300mm             ← 回到原车道中线
  8. 顺/逆时针转90°           ← 车头回原行进方向,继续原路线
```

> 每段的转法(顺/逆)由障碍物在行进方向的**左侧还是右侧**决定;距离按障碍物实际位置量。
> **绕行段全部由"前进/后退/转90°"三种积木组成**——车端能力已覆盖,不需要新功能。

## 六、执行方式(不变)

- **单步**:上位机逐帧发 04 动作帧(每帧=车端任务表前进一步);
- **一键**:发 `AA 55 12 12 0D 0A`,从当前步骤连跑;
- **任务步骤表**(`task_z1[]`)把上面第二/三节的段补齐后,0x12 即可跑全流程;
- 机械臂取放期间:车停在上一步位置,**上位机不发下一帧即保持停止**(单步模式天然支持;一键模式需要"等待步"类型,待机械臂联调时加)。
