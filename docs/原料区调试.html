本次执行流程

  1. 当前朝向记为90°；A槽30°，同步带7040、RM455°准备，夹爪25°张开。
  2. 视觉中心定位到(320,240)±3像素；RM285°与丝杆21000准备抓取。
  3. 只发送一次当前颜色，等RDK抓取触发；总等待30秒，超时停车。
  4. 79°夹紧等400ms → 丝杆12500 → 同步带1400与RM107° → 丝杆19500 → 25°松开等400ms。
  5. 前两块返回7040 / 285° / 21000，并将槽位转到150° / 270°，继续下一块。
  6. 第三块收尾到同步带1400、RM107°、丝杆12500、夹爪25°、A槽30°，独立调试停车；里程计全程持续读取。

丝杆/同步带只等9F主动到位通知，不进行位置回读；丝杆最多等1秒、同步带最多等2秒，未确认也放行，已确认则提前继续。放行不代表实际到位。RM反馈有效时最多等3秒，提前到位则立即继续，未到位也放行；RM反馈失效仍停车并蜂鸣约5秒。屏幕9F:Y/N表示是否收到主动到位帧。舵机槽位只下发角度、不等待反馈。
